# 个人工作台交互原型 · 融合修订版

这是用于比较设计方向的临时原型，不是插件实现。所有资源均为演示数据；整理、收藏、记忆、技能和 AI 回复只保存在当前页面内存中。刷新页面恢复初始状态。

## 本地预览

在仓库根目录运行：

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory client/project-tree/prototype
```

打开 http://127.0.0.1:4317/?variant=A&skin=graphite 。也可以直接打开 `index.html`，无需安装或构建。

## 三种布局，四套皮肤

保留三种结构：A 搜索工作台、B 运维控制台、C 专注空间。底部切换方案，或在未编辑输入框时用左右方向键；`⌘K` / `Ctrl+K` 聚焦搜索。

右上角选择石墨白、深空蓝、松石绿或暖砂金。皮肤与布局完全独立，切换保留树、Tab、技能及会话。URL 用 `variant=A|B|C` 与 `skin=graphite|midnight|forest|sand` 记录外观选择。

新版吸收参考 `client/project-tree/workbench-prototype.html` 的直接树控件、工作场景、搜索范围、项目路径及分支、Host 矩阵和已有项目筛选。字体正文 14–16px，辅助文字不小于 12px；内容扩展至最大 1440px，并减少首页标题区域留白。手机端使用侧栏抽屉和单列卡片。

## 推荐体验顺序

1. 在 A 查看项目卡，切换场景、Host Tab 与搜索范围；“添加项目”可以搜索名称/目录并按 Host 筛选。
2. 左侧体验嵌套分类、拖动、移动、排序、隐藏和合并层级；直接切换原生视图。快照保存与恢复树和 Tab 的展示配置；新创建的资源会保留。
3. 在 B 切换 Host 矩阵和状态列表，打开同一逻辑项目，分别查看不同 Host 的目录。
4. 在 C 查看项目上下文和常驻对话，切换引用项目；会话实际位置和引用项目分别展示。
5. 打开“AI 工作空间”。默认项目为“个人 AI”，默认工作空间由配置 Host 承载。右侧可查看目录、技能和已确认记忆。
6. 点击示例“在 Dev Server 创建一个「日志分析」项目，并新建工作区和会话”。编辑名称、Host、目录，模拟创建后检查项目树、首页卡片、搜索和新会话。再试“在 Paseo Toolkit 下创建工作区「接口联调」”及“在个人 AI 创建会话「发布计划」”。
7. 技能中心可启用/停用预装技能、添加自定义技能定义。停用 Paseo 系统操作技能后，创建方案不可执行。指定离线 Host 时会保留该目标并禁用创建。
8. 普通示例问答可保存为记忆候选；确认后进入上下文，支持停用与移除。

## 默认 AI 项目约定

建议默认根目录为配置 Host 上的 `~/.paseo/workbench`；本原型用本地主机的 `~/.paseo/workbench` 展示。该目录没有被真实创建，也不是已确定的 Paseo 标准。

```text
workbench/
├── AGENTS.md
├── .agents/skills/
│   ├── paseo/SKILL.md
│   ├── workspace-guide/SKILL.md
│   └── environment-review/SKILL.md
├── memory/
└── sessions/
```

预装 Paseo 系统操作、工作空间约定、环境检修三个技能。自定义技能演示只保存名称、目录标识和描述；正式实现时应写入实际 SKILL.md，并适配所选 Agent provider 的技能发现方式。`memory/` 和 `sessions/` 只是建议组织方式，真实会话仍应由 Paseo 管理，具体索引格式待实施时确定。

实际接入流程应是：确保默认项目与工作空间存在 → 加载技能与允许引用的记忆 → 对话提出创建意图 → 展示明确的 Host/项目/目录/工作区 → 通过公开 Paseo SDK 执行 → 按真实结果刷新资源目录与会话入口。会话所属位置不会因为切换“引用项目”而隐式改变。

## 原型边界

不连接 Paseo、不调用模型、不创建文件、不执行服务器任务。自然语言仅通过少量规则匹配示例意图，复杂表达可能需要手动编辑方案；不是实际的语义解析器。搜索覆盖示例会话与本次模拟创建的会话索引，不包含真实历史记录。Host 连接与 CPU 为静态模拟，工作区总数为演示统计。原生视图也来自演示数据。

方案尚待用户评估，不代表已确认架构或视觉设计。保留在 `prototype/workbench-preview` 分支；确定方向后按插件 React Native 与公开 SDK 约束重新实现，不把此静态原型直接投入生产。
