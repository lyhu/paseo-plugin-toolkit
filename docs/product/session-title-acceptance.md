## 手动复验

1. 在当前工作空间右侧面板菜单或 Command Center 打开「会话列表」，确认单一 tab、包含已归档和没有命名记录的会话。
2. 验证时间倒序、序号、提问轮次、搜索及三个状态筛选；无法读到完整历史时显示「—」，刷新可重新读取。
3. 单击只选中；双击或直接打开图标打开该 Host 的会话。「更多」菜单中的「智能生成标题」只请求命名，不打开调试页或新会话。
4. 切换工作空间与 Host，确认列表和轮次不串用；原生移动端可使用直接打开按钮。
5. 切换至工作台视图，确认工作区下没有会话列表，项目及工作区菜单没有显示/隐藏会话项，旧默认显示设置不再生效。
6. 空闲会话点击「归档新建」，确认立即执行原生 `/clear` 并打开新草稿，模型变慢或失败不阻塞；旧会话仍能从右侧筛选找到。
7. 在模型可用后复验 `/session-title`、行尾命名与自动前 5 轮标题更新；模型未配置或历史读取失败时保留原标题。

命名摘要和失败历史保留在 Host 后台，本次不再以调试面板验收；真实模型成功、桌面视觉和移动端真机边界保留。
