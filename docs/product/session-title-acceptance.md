日期：2026-10-26。规格：[会话列表、智能命名与归档新建 PRD](session-title-prd.md)。

## 当前交付

- 右侧 Explorer 原「智能命名」调试页改为「会话列表」，每个 workspace 复用一个 tab，Command Center 同步改名。
- 默认展示全部会话（含已归档、未命名、从未进行智能命名的会话），提供「全部／进行中／已归档」筛选及搜索。
- 显示序号、标题、最近用户提问时间（无提问时取创建时间）、累计提问轮次与归档状态，时间最近在前；单纯修改标题不把旧会话顶到前面。
- 双击打开对应 Host 的原生会话；另有直接打开图标，支持键盘与移动端。行尾智能命名图标静默触发全量命名，不展示调试页。
- 轮次读取完整可用历史中的用户消息数，独立于前 5 轮命名窗口；缺失历史显示「—」。仅可见行异步读取并缓存，Host 并发上限为 2，不调用模型来计数。
- 「工作台视图」移除工作区下的会话列表、显示/隐藏会话菜单与默认显示开关；旧可见性设置不再恢复侧栏会话。
- 智能命名仍默认关闭自动触发，默认前 5 轮及标题 30 个可见字符可配置；复用 Toolkit 共用模型，保护人工标题。
- 「归档新建」先可靠入队，立即自动提交原生 `/clear`；旧会话后台总结和改名，前台不等待模型。
- 摘要、命名任务与失败记录继续保存在 Host，权限 `0600`，不再作为右侧调试页面展示。

## 手动复验

1. 在当前工作空间右侧面板菜单或 Command Center 打开「会话列表」，确认单一 tab、包含已归档和没有命名记录的会话。
2. 验证时间倒序、序号、提问轮次、搜索及三个状态筛选；无法读到完整历史时显示「—」，刷新可重新读取。
3. 单击只选中；双击或直接打开图标打开该 Host 的会话。行尾智能命名图标只请求命名，不打开调试页或新会话。
4. 切换工作空间与 Host，确认列表和轮次不串用；原生移动端可使用直接打开按钮。
5. 切换至工作台视图，确认工作区下没有会话列表，项目及工作区菜单没有显示/隐藏会话项，旧默认显示设置不再生效。
6. 空闲会话点击「归档新建」，确认立即执行原生 `/clear` 并打开新草稿，模型变慢或失败不阻塞；旧会话仍能从右侧筛选找到。
7. 在模型可用后复验 `/session-title`、行尾命名与自动前 5 轮标题更新；模型未配置或历史读取失败时保留原标题。

命名摘要和失败历史保留在 Host 后台，本次不再以调试面板验收；真实模型成功、桌面视觉和移动端真机边界保留。
