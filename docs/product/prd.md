# Paseo Toolkit 产品需求规格说明书 (PRD)

> **版本**：v0.2.1  
> **状态**：正式维护  
> **维护规则**：本项目业务功能与交互规则以本主 PRD 为单一入口维护；业务功能与交互规则变更直接合并至本主 PRD，严禁碎片化新建 PRD。技术架构、重构与执行计划存入 `.plans/`，严禁写入本 PRD。

---

## 1. 产品定位与目标

`paseo-plugin-toolkit`（安装标识符 `toolkit`）是专为 Paseo 打造的开发者工作区与对话交互增强套件。

当前插件运行要求为 Paseo `>=0.13.0 <0.14.0`；跨 Host 创建和个人 AI 使用该版本的公开 SDK。

### 核心价值

1. **多主机与多工作区分层管理**：通过自定义树形工作台（Workbench），解耦物理主机与项目边界，提供高聚合的跨 Host 自定义层级组织与无缝导航。
2. **提问效率与工作区上下文加速**：提供独立工作区快捷提问库、历史智能沉淀与项目级提示词增强，缩短 Prompt 编写心智负担。
3. **沉浸式对话与时间线交互**：提供吸顶提问、紧凑活动、交互式 Mermaid 图表与已发消息保护，优化长对话浏览体验与信息密度。
4. **统一、安全的 AI 基础配置**：统一管理第三方 OpenAI 兼容模型端点，守护进程端安全隔离凭据，支持工作区精细覆盖。

## 3. 详细功能规格与交互规则

### 3.1 工作台 (Workbench)

#### 3.1.1 核心概念与单点配置机制

- **启用策略**：工作台默认关闭，同一开关统一注册或移除工作台页面、侧栏树和主题贡献。为保证多设备多终端视图一致，**仅在一台稳定在线的主机上启用工作台并保存配置**（该主机即为「配置 Host」）。
- **多端同步**：所有客户端连接该配置 Host 后，均共享同一套目录树结构。其他主机作为「工作区 Host」提供代码运行环境，不额外启用工作台功能。
- **自定义视图名称**：
  - 支持在插件设置中为工作台自定义 **视图名称 (View Name)**。
  - 默认值为 `我的工作台`（留空自动回退为默认值）。
  - 该名称会同步应用在：侧栏标题、顶部 Workspaces 下拉菜单以及移动端独立导航入口。

#### 3.1.2 目录树层级与操作规范

- **层级深度**：文件夹嵌套无产品层数限制；禁止把节点移入自身或其后代。
- **项目与工作区**：
  - 跨 Host 显示组：可将多台 Host 的物理项目合并显示为一个逻辑项目组，项目组直接挂载工作区行。
  - 组织虚拟化：任何移动、合并与重命名仅作用于展示层，**严禁**搬动文件系统实际物理目录、Agent 状态或终端进程。
- **拖拽与交互（桌面与 Web）**：
  - 支持将工作区行拖动到其他项目节点或工作区行上方，改变其显示归属。
  - 文件夹支持拖动排序与移动。
  - 删除文件夹行为：删除文件夹时，其内部子节点（子文件夹、项目与工作区）自动提升至上一级父层，禁止级联丢弃内容。
- **节点操作菜单**：
  - 项目节点三点菜单提供：重命名、移动到、上移、下移、置顶、置底、合并到、取消合并、正常显示、仅显示 Workspace、隐藏整个 Project、新建 workspace。三种显示方式直接位于顶级菜单，互斥且标记当前选项。工作台侧栏不展示工作区下的会话，不提供显示/隐藏会话开关；会话统一在右侧「会话列表」查找，原生视图不变。
  - 顶栏设置菜单提供：“新增树节点...”、“显示隐藏节点”、“取消全部隐藏”、“切换原生视图”。
  - 开启“显示隐藏节点”后，临时恢复完整层级，隐藏和仅显示 Workspace 的 Project 以淡化样式和状态标签呈现；关闭后恢复原显示方式。“取消全部隐藏”将所有 Project 恢复正常显示并退出此管理视图。
  - 分类文件夹始终保留，包括空文件夹，不提供隐藏或合并展示层级。仅显示 Workspace 时，工作区显示在 Project 当前父文件夹（无父文件夹则为根）下，不改变真实归属。旧分类文件夹隐藏、平铺标记会备份后清理。
- **原生能力转发与无缝代理**：
  - 工作区行视觉样式优先镜像 Paseo 原生工作区行。
  - 右键与三点菜单完整转发原生菜单动作（重命名、复制路径、已读状态标记、置顶、标签、归档）。
  - 点击项目行 `+` 呼出原生“新建工作区”弹层，支持跨 Host 范围选择及原生目录/worktree 选项。
  - 工作台项目视图与主机视图点击工作区时打开原生工作区，保留 Agent 与 Terminal 标签；个人 AI 聊天是独立入口。
- **离线与降级保障**：
  - 配置 Host 离线时：本地保留该 Host 的离线缓存，客户端仍可浏览并正常进入其他在线 Host 的工作区；目录编辑操作自动禁用并给予提示。
  - 渲染崩溃防护：若自定义树渲染出现异常，自动优雅降级恢复 Paseo 原生侧栏列表，避免阻塞用户主操作流。

#### 3.1.3 展示恢复与工作台偏好

- 目录变更、工作台标签、收藏项目和关注任务均保存在配置 Host，并以修订号检测跨设备写入冲突。
- 展示快照包含树、标签、收藏项目和场景归属，支持预览、命名快照、恢复与撤销。恢复保留当前关注任务、个人记忆和真实资源，不创建、删除或移动真实项目、工作区、会话和文件；树与偏好修订号均须匹配。
- 四套工作台主题通过 Paseo 官方“设置 → 外观”选择，页面使用宿主主题。
- 网页与桌面端将面包屑、在线状态、外观、刷新及轻量 AI 入口合入 Paseo 自带标题栏，移除重复的 Workbench 标题行，保留宿主关闭及配置 Host 选择动作；移动网页保留原生返回，并将页面导航合入标题区，工具按需展开。原生 iOS/Android 保留宿主原有导航栏。
- 顶部工具栏和右侧入口按钮采用紧凑高度。搜索工作台（A）的搜索范围与快捷操作分别沿搜索框左、右边界对齐，同排展示；窄屏自动换行。
- 搜索框、搜索范围、快捷操作和项目分组标签栏（含右侧添加项目、筛选操作）作为一个完整区域吸顶，项目与搜索结果在其下方正常滚动；全部项目及各分组标签以相同样式显示各自项目数，数量不随当前筛选缩小；分组新增、编辑采用低强调的加号、铅笔图标，添加项目及筛选按钮采用紧凑尺寸，移除重复的项目区标题与说明。
- 恢复保留当前新增资源的可访问性，并将已删除资源的旧引用作为不可用项处理。

#### 3.1.4 个人 AI 与记忆

- 用户显式初始化后，在配置 Host 的 `$PASEO_HOME/workbench` 建立个人工作区；重复初始化复用其身份，不覆盖现有 `AGENTS.md` 或已有内置技能。
- 个人 AI 使用用户选择的 Paseo Provider 与实际发现的模型，以 `provider/model` 创建真实会话；通常的 Provider 工具权限确认仍然生效。工具可读取上下文、准备创建计划以及查询自己准备的计划结果。
- 个人记忆支持新增、修改、删除、确认与启用。仅已确认、已启用且作用域匹配的记录进入上下文；记忆是带来源的参考资料，不是执行授权或成功证明。
- 个人 AI 默认读取个人作用域记忆。上下文有数量和文本预算，禁用与未确认记录不会自动发送给模型。

#### 3.1.5 技能管理

- 技能编辑保存为真实 `SKILL.md` 文件。启用技能位于个人工作区 `.agents/skills`；禁用时移出该发现目录。
- 提供规划、记忆和结果核对三项内置技能，支持自定义技能与内容编辑。
- 启用技能内容在预算内进入新会话上下文；禁用技能不出现在个人 AI 工具读取的技能列表。技能变更对新会话生效。现有会话可能保留已加载内容，不宣称禁用可以撤回既有模型上下文。
- 插件重新加载后，旧个人 AI 会话的 Workbench 工具连接失效；新建个人 AI 会话重新连接。

#### 3.1.6 创建计划与确认执行

- 项目、工作区和会话创建先保存为可审阅计划，明确目标 Host、名称、路径或工作区、Provider 及初始提示词。准备和编辑计划不创建资源。
- 用户确认当前修订版后，才由服务端通过目标 Host 的 Paseo SDK 执行。AI 工具不提供执行接口。
- 本地新项目可创建一个尚不存在的最终目录，其父目录必须存在；远端创建使用目标主机已有目录，不在配置 Host 代建同名目录。
- 状态区分待确认、执行中、完成、取消、失败、部分完成和结果未知。只有真实 SDK 返回的身份可作为成功跳转目标。
- 会话创建失败时保留已创建工作区；进程重启或通讯中断导致结果不确定时不自动重试。已处理计划不能再次执行。

#### 3.1.7 历史搜索

- 历史文本搜索使用用户显式索引的真实会话，按 Host 和会话保存分片；展示索引覆盖范围、进度、失败与取消状态。
- 索引读取用户与助手完整文本，不索引工具输出。每次单会话最多 10,000 条文本与 1,600 万字符。取消、分页缺失或超预算时不替换既有完整索引。
- 支持清除已索引会话；未索引、失败或离线会话不作为已完整搜索的范围。

### 3.2 快捷提问 (Quick Questions)

#### 3.2.1 独立词库与输入框浮层

- **独立范围**：词库按 **工作区独立隔离** 存储，不同工作区维护各自常用话术。
- **快捷浮层 (Popover)**：
  - 点击输入框上方“快捷提问”按钮展开浮层。
  - 实时关键字过滤搜索。
  - 点击行末发送图标直接触发发送（仅当对话处于空闲状态时可用）。
  - 点击文本区域填入浮层下方预览微调编辑区，确认后发送。
- **新建 Agent / 草稿适配**：
  - 在新建 Agent 页面，快捷提问按钮并排展示在“导入会话”旁，点击后将问题填入草稿输入框供二次编辑（Web/桌面端）。

#### 3.2.2 维护管理与防误删

- **手动维护**：支持新增常用 Prompt 模板（单条最长 8,000 字符）、修改内容与调整顺序。
- **防误删保护机制**：点击删除按钮后原位变为确认删除提示，并触发 **2 秒强制倒计时**，倒计时结束后方可确认删除，防止高频误触。
- **显式持久化**：所有新增、排序、编辑与删除在点击底部“保存修改”按钮后一次性提交写入磁盘。

#### 3.2.3 历史智能总结 (History Summarization)

- **步骤流程**：
  1. 扫描当前工作区所有历史会话（包含已归档会话）。
  2. 提取最近的用户提问样本（默认 50 条，支持自定义样本量）。
  3. AI 聚类分析：调用配置的 AI 模型，根据用户设置的 **总结提示词**（Summary Prompt）对样本去重聚类，生成最多 20 条高频候选。
  4. 审核与采纳：候选列表展示原始对话引用（最多 3 条），支持查看原会话、单条微调、勾选批量采纳或舍弃。
  5. 增量合入：保存时自动跳过完全相同的历史提问，增量合入词库。

### 3.3 共用 AI 模型 (Shared AI Models)

- **协议标准**：完全兼容 OpenAI Chat Completions 协议规范（第三方模型 API、本地 Ollama/vLLM 等）。
- **两级配置体系**：
  - 主机级默认模型（Host Default）：供历史总结与提示词增强全局共享。
  - 工作区级覆盖模型（Workspace Override）：单个工作区可指定专属模型或端点。
- **连通性探测**：配置页面支持动态拉取可用模型列表与一键连通性测试。
- **安全与隔离**：
  - API 凭据（API Key 等）仅保存在主机守护进程磁盘（文件权限 `0600`）。
  - RPC 接口仅返回配置状态与脱敏摘要，客户端不接收明文密钥。

### 3.4 对话交互与展示增强 (Chat View Enhancements)

#### 3.4.1 吸顶提问 (Sticky Questions)

- 对话流向上滚动时，当前视口所对应的用户提问卡片固定吸顶在聊天窗口上方。
- 超长文本自动折叠为最多 3 行，提供展开/折叠与一键复制功能。
- 仅在 Web 与桌面端活跃对话窗口生效。

#### 3.4.2 紧凑活动 (Compact Activity)

- 将模型思考过程（Thinking / Reasoning Blocks）以及一系列频繁的工具调用记录折叠成可伸缩卡片。
- 支持详细（Detailed）与折叠（Compact）模式切换。
- 提供三种主题风格：鲜明 (Vivid)、柔和 (Soft)、高对比 (High Contrast)。
- 展开后提供工具调用参数、Diff 变更、搜索引用与子智能体执行链路可视化。
- _配置建议_：推荐将 Paseo 原生工具调用详情设为 Detailed，避免上游提前省略关键参数。

#### 3.4.3 Mermaid 交互图表

- 自动检测助手回答中的 Mermaid 代码块（支持 `flowchart`、`sequenceDiagram`、顶层子图等）。
- 实时在聊天区域内渲染交互式 SVG 图表。
- 支持 25% ~ 400% 缩放平移、全屏全景查看、居中复位与查看原始代码。

#### 3.4.4 已发送消息只读保护

- 在 Web 与桌面端对话流中隐藏针对已发出用户消息的撤回/回滚入口，避免意外破坏分支会话树。

#### 3.4.5 提示词增强 (Prompt Enhancement)

- 点击输入框上方“增强”按钮或发送 `/enhance` 斜杠命令。
- 插件服务端读取当前工作区的轻量上下文（`package.json`、`Cargo.toml`、Git 状态摘要、README/AGENTS 关键说明前 4KB 文本）。
- 调用共用 AI 模型，将简短需求扩充为具备上下文约束、操作范围和验证标准的高质量 Prompt。
- 增强文本自动回填输入框，再次点击“还原”可无损切回原始草稿；移动端提供剪贴板降级。

### 3.5 会话列表、智能命名与归档新建

#### 3.5.1 目标与边界
让会话标题准确表达业务对象、主要目标或待解决的问题，便于在会话列表与历史中识别。早期自动调整，后期保持稳定；长会话由用户主动总结并重新命名；收尾时立即切换新草稿，旧会话成果由后台总结保存。

总结、话题判断和标题生成统一复用 Toolkit 共用 AI 模型，不另建模型配置或调用当前编码 Agent。当前配置为 Host 默认模型，工作区可覆盖；沿用工作区覆盖优先、否则 Host 默认的规则。这里的“全局”指会话所在 Host 的 Toolkit 模型配置，不代表自动跨 Host 共享凭据。摘要仅用于该会话的理解、命名与收尾，不自动加入个人记忆。

#### 3.5.2 自动命名与轮次规则
- **触发与轮次**：
  - 第 1 轮正常完成：总结当前目标，生成首个业务标题；
  - 第 2～5 轮正常完成：更新摘要，判断是否需要调整标题；
  - 第 6 轮起：不再自动调用模型或改名；
  - 手动总结或收尾总结：不受前 5 轮限制。
- **一轮定义**：以用户请求及其对应的完整助手执行为单位。工具调用、进度消息、权限问答和自动续跑不单独增加产品轮次。失败、取消不触发分析；重试正常完成后按同一请求计入。
- **话题变化判断**：同一需求的细化、补充约束以及从方案进入开发不视为换题；主要业务目标变化、用户纠正此前理解或原标题明显不准确时重新生成标题；判断同时参考当前摘要、既有标题和新增对话。
- **标题约束**：生成 4～14 字中文或对应长度英文，默认上限 30 个可见字符；不含标点或占位用语。

#### 3.5.3 会话列表与操作
- 原右侧「智能命名」调试页改为每个 workspace 单一的「会话列表」tab（入口位于 explorer，四字入口为「智能命名」）。
- 列表展示全部会话（默认全部，提供全部/进行中/已归档状态筛选与搜索），显示序号、标题、最近会话时间及累计提问轮次，最近在前。
- 双击或点击操作图标打开会话。
- 更多下拉菜单（宽度 160）收纳：生成标题（后台静默命名）、复制标题、重新命名（人工改名）、永久删除（同时清理 Provider 原始历史，保留项目文件）。
- 数量标题与筛选、刷新同排，标题靠左、按钮组右对齐，筛选位于刷新左侧；今年日期省略年份，30 天内附相对时间。会话行 hover 高亮，显示后台处理进度。

#### 3.5.4 归档新建
- 在「吸顶提问」旁提供「归档新建」按钮。
- **交互与执行**：点击后先向后台持久化命名任务，前台立即向当前输入框提交原生 `/clear`，由宿主归档旧会话并切换到新草稿。前台只等待任务保存的短 RPC，不等待模型、历史读取或标题写回。
- **保护策略**：输入框填充与提交限网页或桌面；当前输入框包含附件、不可编辑或内容已变化时阻止提交，避免命令误入 Agent 对话。
- 验收边界与自测记录见[会话命名验收记录](session-title-acceptance.md)。

### 3.6 统一属性配置控制台 (Settings Console)

#### 3.6.1 架构与设计原则
- **单一入口收敛**：废除在 Paseo 宿主插件列表菜单上分散平铺多个独立设置屏的做法，收敛为唯一的 `Toolkit 设置` 入口。
- **Master-Detail 布局**：宽屏下采用左侧固定导航栏（宽度约 220px）+ 右侧滚动配置面板；窄屏与移动端自动自适应为顶部胶囊 Tab。
- **模块树分类**：
  1. **概览与主控 (Overview)**：展示插件版本、当前连接 Host、子模块启用状态矩阵（支持一键直达对应 Tab），以及全局语言偏好（简体中文 / English / 跟随客户端）。
  2. **对话交互 (Chat Experience)**：紧凑活动（主开关及级联展开/折叠、色板）、Mermaid 图表渲染、吸顶提问与只读消息保护。
  3. **工作台 (Workbench)**：跨 Host 工作台总开关、左侧导航树自定义视图名称与使用提示。
  4. **AI 与模型 (AI & Models)**：配置 Host 级共享模型端点与凭据、测试连通性，并支持针对特定工作区单独覆盖。
  5. **智能辅助 (Smart Features)**：会话智能命名参数配置（总开关、判断轮数 1~20、最大长度 1~100、模型依赖快捷入口）与输入框提示词增强。
  6. **系统与环境 (System & Environment)**：快捷提问库总控开关、macOS 本地编辑器语法着色补丁状态检测与修补/恢复操作。

#### 3.6.2 全局一致性规范
- **分级启停模型 (Hierarchy of Enabling)**：每个子模块卡片顶部统一提供 Master Switch；主开关关闭时，下属子配置项统一自动置灰（Disabled）并禁止编辑，但保留既有数值。
- **显式作用域微标 (Scope Badges)**：所有配置项显式标注生效范围：
  - `[Host]`：当前连接的配置主机全局生效；
  - `[设备]`：当前客户端设备本地偏好生效；
  - `[工作区]`：当前工作区可独立覆盖；
  - `[macOS]`：特定操作系统专属功能。
- **自动保存与校验**：表单变更采用实时失焦自动保存（Autosave on Blur/Change），配合右上角状态提示与错误横幅报警。
- **依赖关联与内聚跳转**：模块间依赖（如会话智能命名依赖 AI 模型）在界面内直接提供内部 Tab 快速切换，杜绝跳出当前页面的破窗体验。

## 5. 数据存储与安全规范

### 5.1 数据路径与契约

所有文件保存在主机守护进程环境的 `$PASEO_HOME` 目录中：

| 物理路径                                                      | 对应模块 | 内容说明                                           | 存储机制                                  |
| :------------------------------------------------------------ | :------- | :------------------------------------------------- | :---------------------------------------- |
| `~/.paseo/toolkit/project-tree.json`                          | 工作台   | 树节点层级、跨 Host 引用、隐藏节点集合、数据修订号 | `RevisionedJsonStorage`（版本号原子更新） |
| `~/.paseo/toolkit/workbench/state.json`                       | 工作台   | 偏好、任务与个人记忆                               | 修订号原子更新，权限 `0600`               |
| `~/.paseo/toolkit/workbench/personal-ai.json`                 | 个人 AI  | 个人工作区身份                                     | 原子写入，权限 `0600`                     |
| `~/.paseo/toolkit/workbench/operations.json`                  | 创建计划 | 审阅内容、执行状态与真实资源身份                   | 原子写入，权限 `0600`                     |
| `~/.paseo/toolkit/workbench/search/<hash>.json`               | 历史搜索 | 会话文本索引分片                                   | 按 Host 与会话寻址，权限 `0600`           |
| `~/.paseo/workbench/.agents/skills/<slug>/SKILL.md`           | 技能     | 启用的个人 AI 技能                                 | 实际 Markdown 文件                        |
| `~/.paseo/workbench/.toolkit/disabled-skills/<slug>/SKILL.md` | 技能     | 禁用技能                                           | 移出技能发现目录                          |
| `~/.paseo/plugin-settings/toolkit/project-tree.json`          | 工作台   | 配置 Host 的工作台开启状态与视图名称               | Paseo 插件设置存储 (v2)                   |
| `~/.paseo/toolkit/models.json`                                | AI 模型  | 主机默认模型、工作区覆盖配置、API Key 凭据         | 敏感存储，文件权限 `0600`                 |
| `~/.paseo/toolkit/quick-questions/<hash>.json`                | 快捷提问 | 工作区专属词库、采样大小、自定义总结提示词         | 工作区隔离存储，按哈希寻址                |
| `~/.paseo/plugin-settings/toolkit/chat-view-display.json`     | 交互增强 | 各功能开关、多语言偏好、紧凑主题配色               | Paseo 插件设置存储                        |

### 5.2 隐私与安全

1. **凭据安全**：API 密钥只存放在主机端，不传输至客户端，不打入客户端构建产物。
2. **纯本地网络传输**：所有模型推理请求直接由守护进程向用户配置的模型端点发起，不经过任何第三方中间代理，不搜集隐私数据。
3. **上下文边界控制**：提示词增强仅提取项目配置清单与简要文档头部摘录，严禁扫描、读取或向模型发送工作区业务源码。
