# 个人工作台交互原型

这是用于比较设计方向的临时原型，不是插件实现。所有资源均为演示数据；整理、收藏、记忆和 AI 回复仅发生在当前页面内存中。刷新页面恢复初始状态。

在仓库根目录运行：

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory client/project-tree/prototype
```

打开 http://127.0.0.1:4317/?variant=A 。也可以直接用浏览器打开 `index.html`，无需安装或构建。

- A：搜索工作台，搜索与项目入口优先。
- B：运维控制台，Host 与环境状态优先。
- C：专注空间，单项目与 AI 对话优先。

底部切换方案，或在没有编辑输入框时使用左右方向键。`⌘K` / `Ctrl+K` 聚焦搜索。

支持演示：分类嵌套、拖动与菜单排序、移动、隐藏、合并层级、原生视图切换、撤销、跨 Host 项目选择、搜索项目与示例对话、自定义 Tab、收藏项目、模拟 AI 问答、记忆候选确认与删除。底部“状态”可检查当前状态。

限制：不连接 Paseo、不调用模型、不执行服务器任务；正文搜索只覆盖三条示例会话；Host 状态和 CPU 数据为静态模拟。原生视图也是模拟视图。方案尚待用户评估，不代表已确认架构或视觉设计。

原型保留在 `prototype/workbench-preview` 分支。用户确定方向后，再按插件的 React Native 与公开 SDK 约束重新实现。
