# Paseo Toolkit

[English](README.md) | [简体中文](README_zh.md)

`paseo-plugin-toolkit` 为 Paseo 提供工作区快捷提问库、对话交互与展示增强、以及统一的共用 AI 模型配置。Paseo 安装 ID 为 `toolkit`。

## 功能概览

| 模块       | 用途                                             | 默认状态 |
| ---------- | ------------------------------------------------ | -------- |
| 项目树     | 自定义文件夹、跨 Host 显示组与紧凑工作区树       | 关闭     |
| 快捷提问   | 工作区话术库、输入框浮层、手动编辑、历史总结候选 | 开启     |
| 吸顶提问   | 滚动时保留当前用户问题                           | 开启     |
| 紧凑活动   | 将推理和工具活动归并为可展开记录                 | 关闭     |
| Mermaid    | 在助手回答中渲染支持的交互图表                   | 关闭     |
| 只读消息   | 在网页界面隐藏已发送消息的撤回操作               | 开启     |
| 提示词增强 | 结合项目上下文扩展简短草稿                       | 关闭     |
| 共用模型   | 总结与增强共用主机默认模型，支持工作区覆盖       | 需要配置 |

## 环境要求与平台支持

支持 **Paseo 0.12.x**（`>=0.12.0 <0.13.0`），客户端和守护进程均需更新。项目基于 SDK 0.12.0 构建。

| 功能               | 桌面端 / 浏览器        | iOS / Android                       |
| ------------------ | ---------------------- | ----------------------------------- |
| 快捷提问、模型配置 | 可用                   | 使用跨平台组件，仍需真机验证        |
| 吸顶提问           | 活跃对话视图可用       | 不可用，依赖网页适配层              |
| 紧凑活动、Mermaid  | 可用                   | 使用跨平台渲染组件，仍需真机验证    |
| 只读消息           | 可用                   | 不可用，依赖网页适配层              |
| 提示词增强         | 输入框按钮、回填、还原 | `/enhance` 与剪贴板降级，不自动回填 |

> **提示**：使用紧凑活动功能时，建议将 Paseo 的工具调用详情设为 **Detailed / 详细**。Overview 模式会在插件收到数据前归并内容，插件将无法恢复被省略的细节。

## 安装与维护

### 从 GitHub 安装

在运行守护进程的机器上执行（确保已启用插件支持，且守护进程环境可访问 Git、Node.js 与 npm）：

```bash
paseo plugin install github:lyhu/paseo-plugin-toolkit --ref main
paseo plugin ls
```

安装 ID 为 `toolkit`，确认状态为 `running`。Paseo 会自动克隆仓库、执行依赖准备（`npm ci --omit=dev --ignore-scripts`）并编译 TypeScript 插件，无需手动构建。

### 从本地源码安装

适用于本地开发调试场景：

```bash
git clone https://github.com/lyhu/paseo-plugin-toolkit.git
cd paseo-plugin-toolkit
npm ci
npm run typecheck
npm run lint
paseo plugin install "$PWD"
paseo plugin ls
```

此方式注册本地目录，源码修改后执行 `paseo plugin reload toolkit` 即可生效。

### 更新与排查

GitHub 安装更新：

```bash
paseo plugin update toolkit
paseo plugin ls
```

本地源码安装更新：在目录中执行 `git pull --ff-only` 与 `npm ci`，然后重载插件：

```bash
paseo plugin reload toolkit
paseo plugin logs toolkit
paseo plugin disable toolkit
paseo plugin enable toolkit
```

**常见排查**：

- **仓库访问失败**：检查守护进程主机的网络连接、Git 凭据或代理配置。
- **依赖准备失败**：确认 npm 可正常调用，并检查 `$PASEO_HOME/daemon.log`。
- **编译/运行异常**：查看插件运行时日志 `paseo plugin logs toolkit`。
- **多主机环境**：连接多台主机时请选择目标主机。插件源码、配置、话术库及凭据均归目标主机独立隔离存储。

## 自定义项目树

在 **设置 → 插件 → toolkit → 项目树** 中，将一台稳定在线的 Host 设为配置 Host。只在这一台 Host 上启用项目树；所有设备连接这台 Host，并可同时连接其他工作区 Host。

- 文件夹最多三层，可重命名、移动与排序。删除文件夹会将内容提升到父层。
- 可将不同 Host 的项目合并为显示组，工作区直接排在组下。显示组织不会搬动目录、Agent 或终端。
- 桌面和网页侧栏使用与原生接近的图标、缩进、`+` 与三点按钮；支持拖动，也可从节点三点菜单移动和排序。
- Workspace 可拖到其他项目标题或其工作区行上，单独改变显示归属；实际 Host、Project、目录与会话不变，位置在配置 Host 持久化。
- Workspace 行优先镜像原生行的视觉内容并同步状态，三点与右键调用原生菜单（含重命名、复制路径、已读状态、置顶、标签与归档）。原生行尚未展开时会尝试展开并加载更多；无法定位时仍提供 SDK 重命名和原生视图入口。
- 项目行的 `+` 直接进入原生“新建 workspace”页面；跨多个原生项目组时先选择 Host 范围。创建页的项目、Host、本地目录或 worktree 选项均沿用原生行为。移动端节点弹层提供按目录创建入口。
- 项目三点菜单提供重命名、移动到、上移、下移、合并到、取消合并和新建 workspace。重命名在节点旁输入，移动和合并直接选择目标；不再提供独立管理页面。顶部设置菜单提供“新增树节点...”和“切换原始视图”，文件夹三点菜单包含移动、排序和删除操作。
- 桌面与网页可切换原生视图；插件停用或适配失败会恢复原始列表。iOS / Android 使用独立项目树页面，尚需真机验收。
- 配置 Host 离线时保留本设备缓存，可打开其他在线 Host 的工作区；目录编辑暂停。视图、折叠与缓存按配置 Host 在本设备分别保存。

侧栏替换与原生菜单转发依赖 Paseo 0.12 的网页结构，需要随宿主升级验证。移动端的简化创建弹层仅支持已有目录；网页和桌面侧栏 `+` 使用原生创建页。插件不会自动归档旧工作区。

## 快捷提问

点击聊天输入框上方的 **快捷提问** 按钮即可打开浮层：

- 支持关键字实时检索。
- 点击行末发送图标直接发送；或点击内容填入浮层编辑区，微调后再发送。
- 仅在对话处于空闲状态时允许触发发送。
- 新建 Agent 时，同一按钮会出现在草稿输入框上方、与 **导入会话** 并排。选择问题后会填入草稿输入框，发送前仍可编辑。该草稿入口需要 Paseo 0.12 或更高版本。填入草稿输入框需要 Web 或桌面端。

点击浮层右上角 **设置图标**（或通过 Command Center）进入当前工作区维护页：

- **手动新增**：支持录入常用提示词或问题模板（单条上限 8,000 字符）。
- **编辑与排序**：使用铅笔图标编辑内容，使用箭头上下调整显示顺序。
- **防误删保护**：点击删除后原位显示确认操作，需等待 2 秒倒计时结束方可确认。
- **显式持久化**：所有新增、修改、排序及删除在点击 **保存修改** 后统一写入存储。

> 快捷提问入口受两级开关控制：主机级全局开关（位于插件功能设置）以及维护页中的工作区级独立开关。

### 从工作区对话智能总结

在维护页中展开 **从工作区对话总结**：

1. **扫描会话**：读取当前工作区可访问的历史对话（包含归档对话）。
2. **抽取样本**：按时间倒序提取最近的 **用户提问样本**（默认 50 条，支持按工作区自定义调整）。
3. **AI 聚类归纳**：将提问结合必要上下文分批发送给配置的 AI 模型，聚类合并为最多 **20 条高频候选**，并优先呈现重复意图。
4. **审核与采纳**：候选列表中可展开查看最多 3 条原始对话引用并支持跳转；支持单条微调、按序号批量采纳或剔除无用候选。
5. **合入词库**：确认后点击保存，系统会自动跳过完全重复的问题并合入当前工作区词库。

用户还可在折叠区域内针对当前工作区自定义 **总结提示词**，灵活引导模型的提炼侧重点。

## 共用 AI 模型

进入路径：**设置 → 插件 → toolkit → Toolkit 模型**，或从快捷提问维护页的 **模型设置** 展开。

- **多层级配置**：支持配置主机默认模型，供所有工作区、历史总结与提示词增强功能共享；各工作区亦可单独配置模型覆盖默认设定。
- **OpenAI 兼容协议**：支持兼容 OpenAI Chat Completions 规范的第三方端点，支持自动拉取模型列表与连通性测试。
- **安全隔离**：模型凭据仅保存在主机守护进程端，界面只返回配置摘要和凭据存在状态，不向客户端明文回传密钥。

## 对话交互与展示增强

### 吸顶提问 (Sticky Questions)

长对话滚动浏览时，当前视口对应的用户原始提问会自动吸顶固定在界面上方。超长文本默认折叠为 3 行，支持展开查看完整内容或一键复制。

### 紧凑活动 (Compact Activity)

将模型的深度思考（Thinking/Reasoning）和繁琐的工具调用合并为整洁的可展开活动组。

- 支持在功能设置中切换折叠模式或详细模式。
- 提供鲜明 (Vivid)、柔和 (Soft) 和高对比 (High Contrast) 样式配色。
- 展开后可查看工具参数、差异比较 (Diff)、检索结果及子代理调用链路。

### Mermaid 交互图表

在助手回答中直接将 Mermaid 代码块渲染为可交互矢量图表：

- 支持缩放（25% ~ 400%）、自适应居中、源码查看和全屏模式。
- 原生支持 `flowchart` / `graph`、`sequenceDiagram` 及顶层子图。

### 已发送消息只读保护

在网页及桌面客户端中隐藏已发送用户消息的撤回/回滚入口，防止误触导致分支会话历史错乱。

### 提示词增强 (Prompt Enhancement)

在输入框上方提供 **增强** 按钮或使用 `/enhance` 命令：

- 结合当前项目元数据、清单依赖、Git 状态及关键说明文档（如 README、AGENTS、CLAUDE、CONTRIBUTING 等有限摘录）。
- 自动将模糊、简短的草稿扩展为具备背景目标、操作范围、技术约束和验收标准的高质量 Prompt。
- 增强完成后自动回填输入框，支持二次点击恢复原始草稿。

## 功能设置与多语言

在 Toolkit 功能设置页面中，可以对各项增强功能进行精细化开关与外观配置：

- **功能开关**：快捷提问、吸顶提问、紧凑活动、Mermaid 图表、只读保护、提示词增强均支持独立开启或关闭。
- **多语言支持**：界面支持 **简体中文**、**English** 与 **跟随系统 (Auto)**。所有面板、提示框、操作说明及任务状态均支持实时多语言切换。
- **数据保留**：语言切换仅作用于界面交互文本；用户录入的话术、历史对话正文及模型生成内容始终保持原始语言。

## 数据存储与隐私

插件数据在主机 `PASEO_HOME` 目录下统一管理：

| 存储路径                                                  | 内容说明                             |
| --------------------------------------------------------- | ------------------------------------ |
| `~/.paseo/toolkit/project-tree.json`                      | 项目树结构、跨 Host 项目引用与修订号 |
| `~/.paseo/plugin-settings/toolkit/project-tree.json`      | 配置 Host 的项目树开关               |
| `~/.paseo/toolkit/models.json`                            | 主机全局模型、工作区覆盖及 API 凭据  |
| `~/.paseo/toolkit/quick-questions/<workspace-hash>.json`  | 工作区快捷提问库、样本量与总结提示词 |
| `~/.paseo/plugin-settings/toolkit/chat-view-display.json` | 功能开关、多语言偏好与展示外观配置   |

- **权限保护**：敏感配置文件（如模型密钥、话术文件）均以 `0600` 文件权限存储。
- **数据隐私**：历史总结与提示词增强仅在用户主动触发时调用，所有网络请求均由本地守护进程直连配置的模型端点，不会向第三方中继服务上传数据。

## 兼容性说明

若环境中同时安装了其他修改 Paseo 聊天时间线展示的插件（例如其他提供紧凑活动或 Mermaid 转换器的插件），建议在设置中按需关闭重复的功能开关，避免因渲染重叠引发显示冲突。

## 项目架构与开发

```text
index.client.tsx       客户端入口与生命周期管理
index.server.ts        服务端入口与生命周期管理
client/
  quick-questions/     快捷提问前端组件、候选管理与任务进度
  models/              AI 模型管理界面
  chat-view/           对话增强组件（吸顶提问、紧凑活动、Mermaid、增强按钮）
server/
  quick-questions/     历史会话读取、总结任务调度与存储持久化
  models/              模型存储、代理请求与连通性探测
  chat-view/           提示词增强服务与项目上下文提取
shared/                RPC 契约定义、校验 Schema 与国际化多语言
```
