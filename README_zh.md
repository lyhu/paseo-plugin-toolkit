# Paseo Toolkit

[English](README.md) | [简体中文](README_zh.md) | [产品主 PRD](docs/product/prd.md) | [文档中心](docs/README.md) | [领域词汇表](GLOSSARY.md)

`paseo-plugin-toolkit` 为 Paseo 提供跨 Host 工作台、个人 AI 会话、工作区快捷提问库、对话展示工具和共用 AI 模型配置。Paseo 安装 ID 为 `toolkit`。

## 功能概览

| 模块       | 用途                                                    | 默认状态 |
| ---------- | ------------------------------------------------------- | -------- |
| 工作台     | 项目与主机视图、个人 AI、记忆、技能、历史搜索与展示组织 | 关闭     |
| 快捷提问   | 工作区话术库、输入框浮层、手动编辑、历史总结候选        | 开启     |
| 吸顶提问   | 滚动时保留当前用户问题                                  | 开启     |
| 紧凑活动   | 将推理和工具活动归并为可展开记录                        | 关闭     |
| Mermaid    | 在助手回答中渲染支持的交互图表                          | 关闭     |
| 只读消息   | 在网页界面隐藏已发送消息的撤回操作                      | 开启     |
| 提示词增强 | 结合项目上下文扩展简短草稿                              | 关闭     |
| 共用模型   | 总结与增强共用主机默认模型，支持工作区覆盖              | 需要配置 |

## 环境要求与平台支持

支持 **Paseo 0.13.x**（`>=0.13.0 <0.14.0`），客户端和守护进程均需更新。项目基于 SDK 0.13.0 构建。

| 功能               | 桌面端 / 浏览器                    | iOS / Android                                       |
| ------------------ | ---------------------------------- | --------------------------------------------------- |
| 工作台             | 浏览器运行验证；沿用原生工作区导航 | React Native 组件测试；尚未启动模拟器或完成真机验收 |
| 快捷提问、模型配置 | 可用                               | 使用跨平台组件，仍需真机验证                        |
| 吸顶提问           | 活跃对话视图可用                   | 不可用，依赖网页适配层                              |
| 紧凑活动、Mermaid  | 可用                               | 使用跨平台渲染组件，仍需真机验证                    |
| 只读消息           | 可用                               | 不可用，依赖网页适配层                              |
| 提示词增强         | 输入框按钮、回填、还原             | `/enhance` 与剪贴板降级，不自动回填                 |

> **提示**：使用紧凑活动功能时，建议将 Paseo 的工具调用详情设为 **Detailed / 详细**。Overview 模式会在插件收到数据前归并内容，插件将无法恢复被省略的细节。

## 安装与维护

### 从 GitHub 安装

在运行守护进程的机器上执行（确保已启用插件支持，且守护进程环境可访问 Git、Node.js 与 npm）：

```bash
paseo plugin install github:lyhu/paseo-plugin-toolkit --ref main
paseo plugin ls
```

安装 ID 为 `toolkit`，确认状态为 `running`。Paseo 会自动克隆仓库、执行依赖准备（`npm ci --omit=dev --ignore-scripts`）并编译 TypeScript 插件，无需手动构建。

### 从本地源码安装

适用于本地开发调试场景：

```bash
git clone https://github.com/lyhu/paseo-plugin-toolkit.git
cd paseo-plugin-toolkit
npm ci
npm run typecheck
npm run lint
paseo plugin install "$PWD"
paseo plugin ls
```

此方式注册本地目录，源码修改后执行 `paseo plugin reload toolkit` 即可生效。

### 更新与排查

GitHub 安装更新：

```bash
paseo plugin update toolkit
paseo plugin ls
```

本地源码安装更新：在目录中执行 `git pull --ff-only` 与 `npm ci`，然后重载插件：

```bash
paseo plugin reload toolkit
paseo plugin logs toolkit
paseo plugin disable toolkit
paseo plugin enable toolkit
```

**常见排查**：

- **仓库访问失败**：检查守护进程主机的网络连接、Git 凭据或代理配置。
- **依赖准备失败**：确认 npm 可正常调用，并检查 `$PASEO_HOME/daemon.log`。
- **编译/运行异常**：查看插件运行时日志 `paseo plugin logs toolkit`。
- **多主机环境**：连接多台主机时请选择目标主机。插件源码、配置、话术库及凭据均归目标主机独立隔离存储。

## 工作台

在 **设置 → 插件 → toolkit → 功能设置 → 工作台** 启用后，从侧栏进入工作台，主机在「全域总览」中查看，技能与记忆在「知行空间」右侧管理。所有设备连接同一台稳定在线的配置 Host，由它保存展示组织和偏好。项目视图与主机视图共用目录数据；点击工作区进入 Paseo **原生工作区，保留 Agent 与 Terminal 标签**。「知行空间」直接打开原生工作区与对话。

工作台默认关闭，只在配置 Host 开启；同一开关控制页面、分组导航和主题。「搜索工作台」统一维护分组名称、关联项目和排序。自定义分组标签支持拖拽排序，**全部项目** 固定首位且不参与拖拽；分组内项目通过卡片上的拖拽手柄排序。编辑分组名称不会改变其位置。

左侧通过 **工作台视图｜原生视图** 两个按钮直接切换，不使用下拉框。工作台视图将所有自定义分组平铺为顶层文件夹，下面展示关联项目及 workspace，顺序跟随搜索工作台；不额外显示「全部项目」组。同一项目可以出现在多个分组并独立展开。原生视图直接显示 Paseo 原生项目树。左侧不提供独立的新建或编辑树节点功能。项目行悬停时显示原生风格的「＋」与「更多」；「＋」打开原生 workspace 创建入口，「更多」复用原生项目设置、新窗口、文件管理器和移除菜单，按宿主能力显示，保留原生确认与 Host 归属。视图选择按设备保存，分组内容与排序保存在配置 Host。已有项目关联与旧组织数据保留，不删除真实资源。工作区继续打开原生标签；全域总览视图独立展示各 Host 的原生项目归属。

搜索工作台的每张项目卡片对应一个 Host 上的原生项目，包含该项目原生归属的全部 workspace，不再按旧显示组合并。旧分组关联会展开为原生项目，包括曾移入旧显示组的 workspace 所属项目。左侧默认显示「分组 → 项目 → workspace」；分组的更多菜单可切换 **只显示工作空间**，隐藏该组内的项目层级。此设置随分组保存，不改变真实资源归属。

项目卡片直接列出全部 workspace；路径单行省略并可复制，项目操作在右上角，每个 workspace 也有更多菜单。桌面与浏览器复用原生项目、workspace 菜单，保留原生 Host 作用范围、设置页与移除确认；项目菜单补充新建 workspace 和分组与场景入口。组内项目通过标题前六点手柄排序。原生 iOS/Android 的卡片操作菜单尚未开放，请使用原生导航操作。

再次进入工作台时，会恢复上次选中的分组、搜索词与范围、Host/场景筛选、筛选面板展开状态及全域总览矩阵/列表选择，按设备和配置 Host 分开保存。A/B/C 布局继续使用设备偏好。已删除的分组会在配置加载后回退到全部项目。

全域总览的项目区显示名称、可复制目录和分支，workspace 以缩进列表区分；长名称单行省略。每个 Host 默认展示最近活动的 5 个原生项目，“更多（剩余数量）…”每次增加 5 个，矩阵与列表共用展开数量。项目活动时间取其 workspace 中最新的用户消息时间；workspace 没有用户消息时间时，回退到原生活动或创建时间，无记录的项目保留原有顺序排在后面。

四套工作台配色在 Paseo 官方 **设置 → 外观** 主题选择器中切换，页面跟随当前宿主主题。插件提供窄屏布局；移动端经过 React Native 组件测试，尚未启动模拟器或完成真机验收。

### 知行空间、记忆与技能

工作台视图在分组上方固定显示「知行空间」。首次打开在 `$PASEO_HOME/workbench` 建立原生工作区；已有工作区和历史会话直接复用，不新建替代资源。点击后打开原生对话，模型、输入框、工具调用和权限确认均沿用 Paseo。原生工作区右上角的「技能与记忆」图标打开右侧「知行上下文」面板，可管理技能、记忆、参考项目与待确认创建方案。窄屏可通过原生侧边面板进入。桌面/Web 的技能「查看内容」在左侧主区打开真实 `SKILL.md` 的原生 Markdown 标签，右侧管理面板保留；重复打开复用原生文件标签。

固定入口不参与拖拽、不提供删除/移除菜单，自定义分组也不会重复展示系统项目。插件不能拦截其他原生入口的删除操作；若工作区不可用会保留原身份并提示恢复，不静默建立替代工作区。普通对话仍可在原生界面整理。

个人记忆支持编辑、确认、启停和删除。只有已确认、已启用且作用域匹配的记录进入上下文；个人 AI 默认读取个人作用域，并限制上下文数量和文本预算。记录是带来源的参考资料，不是操作授权。历史索引不会自动把对话转为个人记忆。

技能保存为真实 `SKILL.md`。启用技能位于 `.agents/skills`，禁用后移出发现目录，也不再出现在个人 AI 工具上下文中。在该目录内通过原生界面创建的新会话同样接入工作台工具，在预算内接收启用技能和已确认记忆；参考项目不会改变实际执行目录。已有会话可能保留先前加载的内容，修改技能后需新建会话。插件重载或重启会使已有 Workbench 工具连接失效，之后需新建个人 AI 会话重新连接。

### 确认创建与历史搜索

创建项目、工作区或会话时，先保存包含目标 Host、目录或工作区、Provider/模型和提示词的可编辑计划。点击 **确认并执行** 后才调用真实 SDK。AI 工具只能准备计划和读取结果，不能执行计划。完成、失败、部分完成、取消和结果未知分别显示，已处理计划不能重复执行。部分完成保留已确认资源身份；结果未知时应先检查目标，再决定是否另建请求。

本地新项目可以创建最后一级目录，其父目录须已存在。远端目标必须预先存在所选目录，插件不会在配置 Host 代建目录。远端操作使用目标 Host 的 SDK 连接。

历史搜索覆盖显式索引的会话，展示覆盖范围和错误。索引读取用户与助手文本，不包含工具输出；取消、缺页或超预算时保留上一次完整索引。每次索引单会话最多 10,000 条文本和 1,600 万字符。结果保留来源 Host、工作区和会话；未索引或索引失败的会话不会被描述为已完整搜索。

## 快捷提问

点击聊天输入框上方的 **快捷提问** 按钮即可打开浮层：

- 支持关键字实时检索。
- 点击行末发送图标直接发送；或点击内容填入浮层编辑区，微调后再发送。
- 仅在对话处于空闲状态时允许触发发送。
- 新建 Agent 时，同一按钮会出现在草稿输入框上方、与 **导入会话** 并排。选择问题后会填入草稿输入框，发送前仍可编辑。填入草稿输入框需要 Web 或桌面端。

点击浮层右上角 **设置图标**（或通过 Command Center）进入当前工作区维护页：

- **手动新增**：支持录入常用提示词或问题模板（单条上限 8,000 字符）。
- **编辑与排序**：使用铅笔图标编辑内容，使用箭头上下调整显示顺序。
- **防误删保护**：点击删除后原位显示确认操作，需等待 2 秒倒计时结束方可确认。
- **显式持久化**：所有新增、修改、排序及删除在点击 **保存修改** 后统一写入存储。

> 快捷提问入口受两级开关控制：主机级全局开关（位于插件功能设置）以及维护页中的工作区级独立开关。

### 从工作区对话智能总结

在维护页中展开 **从工作区对话总结**：

1. **扫描会话**：读取当前工作区可访问的历史对话（包含归档对话）。
2. **抽取样本**：按时间倒序提取最近的 **用户提问样本**（默认 50 条，支持按工作区自定义调整）。
3. **AI 聚类归纳**：将提问结合必要上下文分批发送给配置的 AI 模型，聚类合并为最多 **20 条高频候选**，并优先呈现重复意图。
4. **审核与采纳**：候选列表中可展开查看最多 3 条原始对话引用并支持跳转；支持单条微调、按序号批量采纳或剔除无用候选。
5. **合入词库**：确认后点击保存，系统会自动跳过完全重复的问题并合入当前工作区词库。

用户还可在折叠区域内针对当前工作区自定义 **总结提示词**，灵活引导模型的提炼侧重点。

## 共用 AI 模型

进入路径：**设置 → 插件 → toolkit → Toolkit 模型**，或从快捷提问维护页的 **模型设置** 展开。

- **多层级配置**：支持配置主机默认模型，供所有工作区、历史总结与提示词增强功能共享；各工作区亦可单独配置模型覆盖默认设定。
- **OpenAI 兼容协议**：支持兼容 OpenAI Chat Completions 规范的第三方端点，支持自动拉取模型列表与连通性测试。
- **安全隔离**：模型凭据仅保存在主机守护进程端，界面只返回配置摘要和凭据存在状态，不向客户端明文回传密钥。

## 对话交互与展示增强

### 吸顶提问 (Sticky Questions)

长对话滚动浏览时，当前视口对应的用户原始提问会自动吸顶固定在界面上方。超长文本默认折叠为 3 行，支持展开查看完整内容或一键复制。

### 紧凑活动 (Compact Activity)

将模型的深度思考（Thinking/Reasoning）和繁琐的工具调用合并为整洁的可展开活动组。

- 支持在功能设置中切换折叠模式或详细模式。
- 提供鲜明 (Vivid)、柔和 (Soft) 和高对比 (High Contrast) 样式配色。
- 展开后可查看工具参数、差异比较 (Diff)、检索结果及子代理调用链路。

### Mermaid 交互图表

在助手回答中直接将 Mermaid 代码块渲染为可交互矢量图表：

- 支持缩放（25% ~ 400%）、自适应居中、源码查看和全屏模式。
- 原生支持 `flowchart` / `graph`、`sequenceDiagram` 及顶层子图。

### 已发送消息只读保护

在网页及桌面客户端中隐藏已发送用户消息的撤回/回滚入口，防止误触导致分支会话历史错乱。

### 提示词增强 (Prompt Enhancement)

在输入框上方提供 **增强** 按钮或使用 `/enhance` 命令：

- 结合当前项目元数据、清单依赖、Git 状态及关键说明文档（如 README、AGENTS、CLAUDE、CONTRIBUTING 等有限摘录）。
- 自动将模糊、简短的草稿扩展为具备背景目标、操作范围、技术约束和验收标准的高质量 Prompt。
- 增强完成后自动回填输入框，支持二次点击恢复原始草稿。

## 功能设置与多语言

在 Toolkit 功能设置页面中，可以对各项增强功能进行精细化开关与外观配置：

- **功能开关**：工作台、快捷提问、吸顶提问、紧凑活动、Mermaid 图表、只读保护、提示词增强均支持独立开启或关闭。
- **多语言支持**：界面支持 **简体中文**、**English** 与 **跟随系统 (Auto)**。所有面板、提示框、操作说明及任务状态均支持实时多语言切换。
- **数据保留**：语言切换仅作用于界面交互文本；用户录入的话术、历史对话正文及模型生成内容始终保持原始语言。

## 数据存储与隐私

插件数据在主机 `PASEO_HOME` 目录下统一管理：

| 存储路径                                                  | 内容说明                                             |
| --------------------------------------------------------- | ---------------------------------------------------- |
| `~/.paseo/toolkit/project-tree.json`                      | 工作台结构、跨 Host 项目引用与修订号                 |
| `~/.paseo/plugin-settings/toolkit/project-tree.json`      | 配置 Host 的工作台开关与视图名称                     |
| `~/.paseo/toolkit/workbench/`                             | 偏好、个人记忆、个人 AI 身份、创建计划与历史索引分片 |
| `~/.paseo/workbench/`                                     | 个人 AI 工作区与启用/禁用技能文件                    |
| `~/.paseo/toolkit/models.json`                            | 主机全局模型、工作区覆盖及 API 凭据                  |
| `~/.paseo/toolkit/quick-questions/<workspace-hash>.json`  | 工作区快捷提问库、样本量与总结提示词                 |
| `~/.paseo/plugin-settings/toolkit/chat-view-display.json` | 功能开关、多语言偏好与展示外观配置                   |

- **权限保护**：敏感配置文件（如模型密钥、话术文件）均以 `0600` 文件权限存储。
- **数据隐私**：历史总结与提示词增强仅在用户主动触发时调用，所有网络请求均由本地守护进程直连配置的模型端点，不会向第三方中继服务上传数据。

## 兼容性说明

若环境中同时安装了其他修改 Paseo 聊天时间线展示的插件（例如其他提供紧凑活动或 Mermaid 转换器的插件），建议在设置中按需关闭重复的功能开关，避免因渲染重叠引发显示冲突。
