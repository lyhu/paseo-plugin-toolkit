# Paseo Toolkit

[English](README.md) | [简体中文](README_zh.md)

`paseo-plugin-toolkit` 集成工作空间快捷提问、对话展示工具和共用 AI 模型配置，Paseo 安装 ID 为 `toolkit`。对话工具已从 `paseo-plugin-chat-view` 嵌入，无需同时运行旧插件；隧道功能留待后续迁移。

## 功能概览

| 模块       | 用途                                             | 默认状态 |
| ---------- | ------------------------------------------------ | -------- |
| 快捷提问   | 工作区话术库、输入框浮层、手动编辑、历史总结候选 | 开启     |
| 吸顶提问   | 滚动时保留当前用户问题                           | 开启     |
| 紧凑活动   | 将推理和工具活动归并为可展开记录                 | 开启     |
| Mermaid    | 在助手回答中渲染支持的图表                       | 开启     |
| 只读消息   | 在网页界面隐藏已发送消息的撤回操作               | 开启     |
| 提示词增强 | 结合项目上下文扩展简短草稿                       | 关闭     |
| 共用模型   | 总结与增强共用主机默认模型，支持工作区覆盖       | 需要配置 |

## 环境要求与平台支持

支持 **Paseo 0.10.3 至 0.11.x**（`>=0.10.3 <0.12.0`），客户端和守护进程都需要支持对应插件 API。项目使用 SDK 0.10.3。

| 功能               | 桌面端 / 浏览器        | iOS / Android                       |
| ------------------ | ---------------------- | ----------------------------------- |
| 快捷提问、模型配置 | 可用                   | 使用跨平台组件，仍需真机验证        |
| 吸顶提问           | 活跃对话视图可用       | 不可用，依赖网页适配层              |
| 紧凑活动、Mermaid  | 可用                   | 使用跨平台渲染组件，仍需真机验证    |
| 只读消息           | 可用                   | 不可用，依赖网页适配层              |
| 提示词增强         | 输入框按钮、回填、还原 | `/enhance` 与剪贴板降级，不自动回填 |

使用紧凑活动前，请将 Paseo 的工具调用详情设为 **Detailed / 详细**。Overview 模式会在插件收到数据前归并内容，插件无法恢复被省略的细节。

## 安装与维护

### 从 GitHub 安装

在运行守护进程的机器上执行，并确保 Paseo 已启用插件。守护进程的运行环境需要能够找到 Git、Node.js 和 npm。

```bash
paseo plugin install github:lyhu/paseo-plugin-toolkit --ref main
paseo plugin ls
```

安装 ID 为 `toolkit`，确认状态为 `running`。Paseo 会克隆仓库，按 manifest 执行 `npm ci --omit=dev --ignore-scripts` 安装锁定的运行时依赖，再编译 TypeScript 插件，无需手动克隆或构建。

**仓库目前为私有。** 守护进程所在机器的 Git 凭据必须具有 `lyhu/paseo-plugin-toolkit` 的读取权限。HTTPS 可使用 Git 凭据助手；如果使用 GitHub CLI，可运行 `gh auth login`，再执行 `gh auth setup-git`。仅登录浏览器不会为 Git 提供认证；插件的 AI API Key 与仓库访问权限无关。

### 从本地源码安装

开发插件时使用此方式：

```bash
git clone https://github.com/lyhu/paseo-plugin-toolkit.git
cd paseo-plugin-toolkit
npm ci
npm run typecheck
npm run lint
paseo plugin install "$PWD"
paseo plugin ls
```

同样需要 Git 仓库读取权限。此方式注册本地目录，修改源码后运行 `paseo plugin reload toolkit` 生效。

### 更新与排查

GitHub 安装使用：

```bash
paseo plugin update toolkit
paseo plugin ls
```

出现更新确认时审阅并确认。`--ref main` 只选择首次安装的版本，不会永久锁定版本。本地源码安装则执行 `git pull --ff-only`、`npm ci`，再重载插件，不使用托管来源更新命令。

```bash
paseo plugin reload toolkit
paseo plugin logs toolkit
paseo plugin disable toolkit
paseo plugin enable toolkit
```

仓库访问报错时，检查守护进程机器上的 Git 认证；依赖准备失败时，检查 npm 是否可用及 `$PASEO_HOME/daemon.log`；编译或运行失败时，查看 `paseo plugin logs toolkit`。

连接多台主机时请选择目标主机。插件源码、设置、话术与凭据归对应主机所有。更新或重载插件无需重启 Paseo 主守护进程。

## 快捷提问

点击聊天输入框上方的 **快捷提问**。可以搜索列表、点击行末发送图标直接发送，或选中问题后在浮层编辑再发送。对话空闲时才允许发送。

浮层右上角的 **设置图标** 打开当前工作区维护页，也可以从 Command Center 搜索进入。

- 手动新增话术，每条最多 8,000 字符。
- 使用铅笔图标编辑、箭头调整顺序。
- 使用垃圾桶图标发起删除，原位显示确认和取消图标，等待两秒后才能确认。
- 点击 **保存修改**，持久保存新增、编辑、排序与删除。删除确认只修改草稿，保存后才生效。

快捷入口同时受两个开关控制：Toolkit 功能设置中的主机级 **快捷提问** 开关，以及维护页的工作区入口开关。关闭主机开关会隐藏输入框入口并禁止通过该入口发送，维护页与已保存话术仍保留。

### 从工作区对话总结

展开 **从工作区对话总结**，启动总结。需要先配置模型，未配置时会显示提示。

1. 查找当前工作区可访问的对话，包含归档对话。
2. 按用户消息时间，在这些对话中选择最近 **50 条用户提问**，不是 50 个对话。可在此区域修改并保存正整数条数，各工作区独立配置。
3. 将用户提问及必要的相邻助手文本分批发送给模型，归并为最多 **20 条候选**，按估算频次排序，让重复意图靠前。
4. 候选按带序号的紧凑记录展示，可以编辑、选择前 N 条或逐条勾选。加号添加单条；减号从本轮候选移除；来源图标展开最多三条来源并打开原始对话。
5. 加入话术库后点击保存。已有话术保留，完全重复的文本跳过。

可折叠的 **总结提示词** 位于历史总结区域内，按工作区编辑和保存。还原图标恢复默认文本，保存后用于下一次总结；JSON 输出结构与来源校验仍由插件固定。

执行进度包含历史读取、提问数量、模型批次、合并轮次、读取失败对话，以及最近 100 条带时间记录。可以取消或重试。模型格式无效时，该批次或归并请求会自动重试一次；手动重试会重新读取历史、生成候选。

频次是估算值：语义归类依赖模型，分批 Top20 可能淘汰局部低频问题，不是全局精确计数。已删除或不可恢复的对话无法参与。任务开始时固定本次会话目录。任务和候选暂存在内存，插件重载或守护进程重启会清除；已保存话术保留。

## 共用 AI 模型

从 **设置 → 插件 → toolkit → Toolkit 模型** 进入，或在快捷提问维护页展开 **模型设置**。

主机默认模型只需配置一次，同一主机的各工作区、历史总结与提示词增强共用。工作区可以单独覆盖，也可恢复使用主机默认；不同主机之间不共享凭据。

填写兼容 OpenAI Chat Completions 的 Base URL、模型名称和可选 API Key。支持根据地址和密钥获取模型列表、搜索选择，也可手动填写。**测试连接** 会检查连接和 JSON 输出，总结服务需要支持 `response_format: json_object`。

已保存密钥时，输入框留空会保留密钥，明确点击清除操作才删除。客户端只获得配置摘要及密钥是否存在，不会获得已保存密钥。

## 已嵌入的 chat-view 功能

### 吸顶提问

滚动时在输入框上方保留当前用户问题。长问题折叠为三行，可以展开或复制。依赖网页活跃对话的输入框与视口，没有对应输入框的归档视图不显示吸顶浮层。

### 紧凑活动

将推理和工具调用展示为可展开活动组。在功能设置选择折叠或详细模式，以及鲜明、柔和、高对比配色。支持工具输出、差异、搜索结果和子代理活动等详情；关闭后恢复宿主渲染。

### Mermaid 交互图表

将支持的 Mermaid 代码块渲染为图表，支持适应视图、25% 至 400% 缩放、查看源码和全屏。支持 `flowchart` / `graph`、顶层子图和 `sequenceDiagram`；嵌套子图、`classDef` 等样式指令不在支持范围，显示源码或错误状态。

只有包含 Mermaid 的回答使用插件的轻量 Markdown 渲染，这类回答不具备宿主原生复制、分叉操作；普通回答保持宿主渲染。

### 已发送消息只读

在网页和桌面界面隐藏已发送消息的撤回操作，减少误操作。这是界面保护，不是服务端权限规则。

### 提示词增强

在功能设置启用增强，配置共用模型后，使用输入框上方的 **增强** 或 `/enhance`。可将简短草稿扩展为包含目标、范围、约束和验收条件的请求。网页增强成功后回填草稿，再次点击可以还原，发送前由用户确认内容。

超过 200 字符、过短或已经结构化的输入可能保持原样。模型报错时保留原草稿。项目上下文包括元信息、项目清单与脚本、Git 信息，以及 README、AGENTS、CLAUDE、CONTRIBUTING 等项目说明文件的有限摘录；模型不获得工具。原生客户端没有自动回填能力，使用斜杠命令与剪贴板降级。

## 功能设置与国际化

Toolkit **功能设置** 提供快捷提问及各项对话工具的独立开关，同时配置紧凑活动展示、配色和界面语言。

支持 **简体中文**、**English** 和 **自动**，默认简体中文。自动模式跟随浏览器语言；没有浏览器语言检测能力的原生环境回退中文。打开的面板、输入框入口、模型表单、总结进度、错误及操作提示会跟随界面语言切换；同一主机的其他客户端通过轮询同步设置。

用户话术、历史原文、总结提示词、模型名称与模型生成内容保持原样。切换界面语言不会翻译这些内容，也不会强制模型的输出语言。

## 数据存储与模型请求

默认 Paseo Home 下的存储位置：

| 路径                                                      | 内容                                |
| --------------------------------------------------------- | ----------------------------------- |
| `~/.paseo/toolkit/models.json`                            | 主机默认模型、工作区覆盖与 API 凭据 |
| `~/.paseo/toolkit/quick-questions/<workspace-hash>.json`  | 话术、历史条数、总结提示词          |
| `~/.paseo/plugin-settings/toolkit/chat-view-display.json` | 功能开关、语言与展示偏好            |

设置 `PASEO_HOME` 可覆盖根目录。工作区按 ID 区分，不按文件路径合并。话术与模型文件权限为 `0600`。多端保存使用版本校验；冲突时保留当前草稿，可复制需要的内容后载入最新版本。

历史总结仅在主动触发后运行，将所选用户提问及必要的相邻助手文本发送到配置的模型服务；不单独读取工具输出、推理或附件正文作为总结来源。增强发送草稿及上述项目上下文。两项功能都从守护进程调用配置的模型服务，不给模型工具能力。

## 迁移与插件重叠

首次加载且 Toolkit 尚无对应设置时，导入旧 chat-view 展示偏好。初始化共用模型时优先沿用旧增强配置，否则沿用已有总结配置；不同的工作区总结模型保留为覆盖，与默认一致的自动继承。已有 Toolkit 配置不会被覆盖。

旧源码和配置文件保留。先验证 Toolkit，再停用旧 `chat-view`，避免重复按钮与时间线转换。其他插件的紧凑活动、推理展示、Mermaid 转换器也应避免同时覆盖同类内容。`paseo-plugin-tunnel` 尚未迁移，继续独立运行。

## 架构与开发验证

```text
index.client.tsx       客户端注册与清理
index.server.ts        服务端注册与清理
client/
  quick-questions/     话术库、候选、浮层、进度
  models/              共用模型配置界面
  chat-view/           嵌入的展示和增强界面
server/
  quick-questions/     历史读取、总结任务、持久化
  models/              模型配置仓库、接口探测
  chat-view/           增强与项目上下文
shared/                RPC 契约、Schema、翻译
```

保持客户端、服务端、共享代码的运行时边界，在入口显式装配各模块。后续迁移隧道使用独立模块目录，不复用 chat-view 命名。

```bash
npm run typecheck
npm run lint
npm run format:check
npm run test -- run shared/i18n.test.ts --bail=1
npm run test -- run server/quick-questions/jobs.test.ts --bail=1
```

按改动运行相关测试文件。编译注册测试可通过 `PASEO_SOURCE_DIR` 指向本地 Paseo 源码。模型接口测试使用本地 HTTP 服务，通过并不代表真实模型端点已验证。
